HOW IT'S ATTACHED
================================================================================

1. Database (SQLite) ←→ Prisma Client
   - Prisma reads schema.prisma
   - Generates database client
   - Provides TypeScript types

2. Prisma Client ←→ API Routes
   - API routes import db from @/lib/db
   - Use db.table.create(), db.table.find(), etc.
   - All CRUD operations available

3. API Routes ←→ Frontend
   - Frontend makes fetch() calls to API
   - API returns JSON data
   - Frontend displays data

Flow: Database → Prisma → API → Frontend

Example:
Frontend → fetch('/api/services')
        ↓
API Route → db.service.findMany()
        ↓
Prisma → SELECT * FROM services
        ↓
Database → Returns data
        ↓
API → Returns JSON to frontend
